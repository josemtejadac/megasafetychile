# Mega Safety Chile

Sitio web de Mega Safety Chile — artículos de seguridad industrial (EPP).

Landing estática (HTML/CSS/JS, sin build) desplegada en Cloudflare Pages.

## Desarrollo local

Abre `index.html` directamente en el navegador, o sirve la carpeta con cualquier servidor estático.

## Deploy

- **Producción:** rama `main`, deploy automático vía Cloudflare Pages.
- **Build command:** ninguno.
- **Build output directory:** `/` (raíz del repo).
